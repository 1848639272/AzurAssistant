# 蔚蓝助手

蓝色星原：旅谣自动化辅助 · v0.1.0 beta

蔚蓝助手（AzurAssistant）是一款基于计算机视觉的《蓝色星原：旅谣》自动化辅助，通过图像识别、OCR 与模拟键鼠操作，处理日常领奖、副本挑战、剧情与采集交互，并提供地图定位和路线管理。

[功能](#功能) · [下载与安装](#下载与安装) · [使用方法](#使用方法) · [更新](#更新) · [当前支持范围](#当前支持范围) · [构建与发布](#构建与发布)

## 功能

### 一条龙

勾选需要的项目，按顺序执行。启动与进入游戏固定在前，关闭游戏固定在末尾；中间项目可拖动调整顺序。

- **启动游戏**：根据设置中的游戏启动路径打开游戏。
- **进入游戏**：处理开始旅程、已支持的登录领奖弹窗，并确认进入大世界。
- **领取邮件**：领取当前可领取的邮件附件，完成后返回大世界。
- **家园中枢**：检查并补充奇波餐桌饱腹值，收取建筑与牧场产出；牧场没有产出时跳过收取。
- **日常周常领取**：领取已完成任务的活跃度和可领取的活跃度宝箱奖励。
- **通行证领取**：领取通行证经验与当前可领取奖励，处理升级提示。
- **往厄残影**：选择副本、难度与队伍，执行挑战和领奖；记录本周已确认领取次数，达到周上限时跳过。
- **日常委托**：按基础材料、首领挑战、武备获取选择副本，设置难度与队伍，执行挑战和领奖。
- **危机讨伐**：配置难度、惊喜副本和普通副本；两类副本可独立启用，并分别设置领取上限。
- **主线委托**：选择章节、关卡与队伍，重复挑战所选关卡并领取奖励。
- **关闭游戏**：一条龙结束后按设定等待时间关闭游戏，可同时关闭助手。

副本挑战使用**游戏内自动战斗**。往厄残影、日常委托、主线委托和两类危机讨伐均可设置最多领取份数；奖励倍率计入领取份数。运行前请确认副本、队伍和领取上限。

### 实时辅助

- **自动跳过对话**：识别剧情快进箭头及已支持的剧情确认弹窗，执行对应交互。
- **自动拾取采集物**：识别采集提示后按 `F`，剧情期间暂停采集。

### 导航测试

- **实时定位**：显示当前地图、角色 X/Y 坐标和朝向。
- **地图传送**：选择目标地图和传送点，执行地图切换、查找与传送。
- **坐标移动**：前往角色当前地图内的指定坐标；单点测试限制在起点 250 个地图参考像素内。

当前地图目录包含**夏露露村、新芽山谷、弗利斯城邦**，共 25 个传送目标。地图坐标使用各地图底图像素，不是游戏引擎坐标；部分目标和显示条件仍待实机验证。

### 路线管理

- **记录点位**：手动记录角色当前位置，为路线和各点位命名。
- **保存与交换**：保存路线，导入或导出蔚蓝助手格式的 JSON 文件。
- **运行路线**：在同一地图内依次前往已记录的点位，途中自动转向与前进。
- **沿途拾取**：每条路线可单独开启自动拾取辅助。

请在转弯和障碍附近补充点位。当前路线不自动绕障，也不支持跨地图路线。

### 通用设置

- **启动行为**：可选择启动助手后自动连接游戏画面，或自动运行已保存的一条龙配置。
- **任务控制**：支持暂停、继续、停止和自定义快捷键。
- **画面与日志**：控制台显示游戏预览和运行日志；可关闭预览，日志及异常留证保存在本地。
- **低配模式**：降低任务执行速度与预览刷新频率。
- **深色模式**：切换深色界面。
- **更新检查**：支持每日首次启动检查和手动检查，发现新版本后提示安装。

## 下载与安装

系统要求：**Windows 10 2004 或更高版本，x64**。当前识别资源以**中文游戏界面、1920×1080 客户区**为基准，目标进程为 `AzurPromilia.exe`。

使用名称以 `-win-x64-setup.exe` 结尾的**完整 EXE 安装包**。安装包内置 .NET 运行环境，并在需要时安装 Visual C++ 运行库；使用程序无需安装 .NET SDK。

当前可使用已提供的完整 EXE。GitHub 仓库创建并发布后，完整安装包将在该仓库的 **Releases** 页面提供，下载链接届时补充。

## 使用方法

1. 安装并启动蔚蓝助手，在 Windows 权限提示中允许管理员权限。
2. 打开「设置」，选择游戏启动文件。
3. 在「一条龙」或「实时辅助」中勾选功能；运行副本前展开对应设置，选择副本、队伍与领取上限。
4. 点击「开始」或「运行一条龙」，在控制台查看画面、状态与日志。
5. 使用快捷键暂停或停止任务；修改「设置」页选项后重启助手，使新设置生效。

| 默认快捷键 | 操作 |
|---|---|
| `F9` | 暂停 / 继续当前任务 |
| `F10` | 停止所有任务 |

首次启动默认不连接游戏，也不自动运行任务。快捷键可在设置中更改。停止后重新开始会从任务起点执行。

导航与路线功能请从对应页面操作：定位后先停止当前任务，再传送、移动或记录下一个点位。运行路线前，应让角色进入该路线所属地图。

## 更新

- **自动检查**：在设置开启「自动更新」并重启后，每天首次启动检查 GitHub；发现新版本时弹窗提醒，由你确认下载和安装。
- **手动检查**：点击「检查更新」可随时再次检查，关闭当天的更新提醒后也可使用。连接 GitHub 失败时会提示检查网络。
- **完整包覆盖升级**：也可关闭助手，运行最新完整 EXE 并沿用原安装目录，无需逐个安装中间版本。

更新保留设置、委托记录、周本记录、用户路线和日志。安装完成后的首次启动会跳过自动连接与自动一条龙；之后正常启动按已保存设置执行。

**当前 GitHub 更新仓库尚未配置**，检查更新会提示尚未配置仓库。接入真实仓库后才能联网获取新版本。

## 当前支持范围

当前版本处于 beta 阶段，部分真实游戏流程、地图目标和异常分支仍在验证中。

- 中文 1920×1080 是当前识别基准；其他分辨率、HDR、独占全屏及长期无人值守尚未完成验证。
- 导航和路线暂不支持自动绕障；长距离路线、部分传送目标仍需实机验证。
- 切换账号后，请在一条龙的往厄残影设置中重置周本记录，避免沿用上一账号的记录。
- 识别失败、画面过期或窗口状态异常时，程序会停止当前操作或等待重新观察。遇到问题可查看程序目录中的 `logs/`。

## 构建与发布

### 从源码构建

安装 .NET SDK 10.0.400（或同系列更新补丁），在仓库根目录运行：

```powershell
dotnet build AzurAssistant.sln -c Release
```

构建后的可执行文件位于 `AzurAssistant/bin/Release/net10.0-windows10.0.19041.0/AzurAssistant.exe`。源码仓库不预置编译结果；构建目录、缓存和用户数据已由 `.gitignore` 排除。

### 生成完整安装包

完整发布使用 PowerShell 7：

```powershell
pwsh -File scripts/Build-Release.ps1 -CompilerPath C:/Tools/Inno/ISCC.exe -VCRedistPath C:/Tools/vc_redist.x64.exe -OutputDirectory D:/Releases/AzurAssistant/v0.1.0
```

Inno Setup 6.7.3 和微软签名的 x64 Visual C++ v14 完整离线运行库仅在打包时使用；完整安装包内置 .NET 和 VC++ 依赖。`OutputDirectory` 需为新的空目录，省略时默认 `out/v0.1.0`；仅输出 `program/`、`release/` 和发布说明。再次发布使用递增 BuildNumber（默认 UTC 秒），GitHub Release 标签使用清单中的 ReleaseId，附件上传 `release/` 内的 EXE、`release-manifest.json` 和 `SHA256SUMS.txt`。

### 接入 GitHub 更新

在 [update-source.json](AzurAssistant/update-source.json) 设置真实 `owner/repository` 后重新构建完整包。已发布的 beta Release 参与更新检查，草稿不参与。当前空地址版本需要先手动安装接入仓库地址的新版，之后才能通过程序检查后续更新。

## 文件说明

| 文件或目录 | 用途 |
|---|---|
| `AzurAssistant.sln` | 正式程序解决方案 |
| `AzurAssistant/` | WPF 程序源码及项目文件 |
| `AzurAssistant/assets/` | 程序图标、裁剪识别模板、导航底图与特征 |
| `AzurAssistant/models/` | 本地 OCR 模型、清单和字典 |
| `AzurAssistant/licenses/` | 第三方许可与通知 |
| `AzurAssistant/update-source.json` | GitHub 更新仓库配置，当前为空 |
| `AzurAssistant/release.json` | 开发版本标识；打包时在临时副本生成正式构建号 |
| `scripts/Build-Release.ps1` | 完整程序与 EXE 安装包构建入口 |
| `installer/` | 安装、覆盖升级和卸载脚本及中文翻译 |
| `global.json`、`NuGet.config` | SDK 版本与依赖还原配置 |
| `.gitignore` | 排除构建输出、缓存和用户数据 |

识别模板、导航底图/特征和 OCR 模型是运行必需文件；源码与程序包均需保留这些资源，无需开发原始录屏或训练环境。
